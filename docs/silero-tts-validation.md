# Silero TTS: реализация и проверка

21 октября 2026. Добавлен адаптер `SileroSynthesizer`, русский `v4_ru`,
голос по умолчанию `xenia`, 24000 Гц, PCM16 mono, CPU. SAPI, Edge и ElevenLabs
сохранены. Пользовательский выбор остался **ElevenLabs**, тишина **650 мс**.
Новый движок нужно выбрать самостоятельно в прежних настройках/карточке.

## Версия, зависимости и лицензия

Совместимость `v4_ru`/`xenia`/24000 подтверждается официальной
[таблицей V4](https://github.com/snakers4/silero-models#v4) и
[models.yml](https://github.com/snakers4/silero-models/blob/master/models.yml).
Проверено реальным запуском CPU PyTorch **2.10.0+cpu**, Python 3.12; CUDA
отсутствует. Установка: `.venv/Scripts/python.exe -m pip install -r requirements-silero.txt`.
PyTorch — опциональная зависимость: другие движки не импортируют его при старте.

В этой версии интерфейса разрешена одна проверенная версия модели — `v4_ru`,
без `latest` и произвольных URL. Голоса: aidar, baya, kseniya, xenia, eugene.
Реальная модель объявляет эти голоса; производительность измерена для xenia.
Пакет 40 107 184 байта, SHA-256:
`896ab96347d5bd781ab97959d4fd6885620e5aab52405d3445626eb7c1414b00`.
Хэш зафиксирован по полученному с официального HTTPS-адреса артефакту;
проверка целостности выполняется **до** `PackageImporter.load_pickle`.
torch.hub и выполнение изменяемого кода ветки master не используются.

Официальный README сокращённо называет основную лицензию CC-NC-BY, но полный
[LICENSE](https://github.com/snakers4/silero-models/blob/master/LICENSE)
содержит **CC BY-NC-SA 4.0**. MIT-исключение для CIS base к v4_ru не относится.
Для этих весов указаны некоммерческое использование, атрибуция/источник,
сохранение лицензии/уведомлений, указание изменений и ShareAlike для адаптаций
при распространении. Коммерческое использование требует отдельного разрешения.
Подробности и копия лицензии — [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
Веса не включаются в исходный дистрибутив, `models/` исключён.

## Интеграция и отмена

Модель загружается при первом запросе в существующем executor, не в GUI.
Прежний индикатор показывает загрузку из сети, загрузку в память и готовность;
ошибки поступают через прежний канал уведомлений. Подготовка идёт до запроса
LLM, чтобы ошибка локального TTS не расходовала его квоту.

Кэш `models/silero-tts/v4_ru.pt`: загрузка во временный `.part`, проверка хэша,
атомарная публикация. При ошибке/отмене временный файл удаляется. Повреждённый
существующий кэш не исполняется и не маскируется автоматическим обновлением.
Проверенная модель остаётся в RAM между ответами/перезапусками DialogRuntime;
хранится одна копия на процесс. При следующем запуске используется диск без сети.

Один synthesis executor, по умолчанию два intra-op потока PyTorch, inter-op=1;
в настройках допускается 1–4 intra-op. Это ограничение вычислительного
параллелизма, не жёсткая квота CPU операционной системы. GPU не используется.

Сохранены SentenceChunker/ранний первый фрагмент, credits, очередь PCM,
QAudioSink reuse, токены и поколения отмены, существующая защита от эха.
Длинные предложения дополнительно делятся по словам до 240 символов.
Один `apply_tts` возвращает готовое аудио фрагмента: **это не нативный
потоковый синтез Silero**. Следующие фрагменты последовательно синтезируются
при готовности очереди. PCM передаётся напрямую; WAV/других аудиофайлов нет.

`apply_tts` нельзя остановить посередине нативного вычисления: при отмене
выход Alice сбрасывается существующим механизмом, событие отмены проверяется
до/после загрузки и inference. Поздний результат отбрасывается, следующие
фрагменты отменённого ответа не запускаются. Shutdown ждёт native worker вне
GUI. Время возврата coroutine cancel не называется временем остановки звука.

## Реальная модель: измерения

Основная серия запущена отдельно от тестов/загрузок. Четыре фиксированные
русские фразы длиной 26–64 символа по пять раз: **20 повторов**, после
отдельной холодной попытки. Короткие результаты соответствуют примерно
1,9–3,7 секунды сгенерированной речи. Сеть блокировалась на уровне socket;
обращений **0**. Модель и CPU PyTorch настоящие, LLM не используется.
Скрипт: `scripts/qa_silero_tts.py`; данные:
[silero-real-results.json](silero-real-results.json).

| Показатель | Медиана | p95 |
|---|---:|---:|
| Запрос фрагмента → готовый первый PCM | 67,3 мс | 372,6 мс |
| Процессорное время процесса на вызов | 125,0 мс | 468,0 мс |
| CPU процесса, 100%=одно логическое ядро | 198,0% | 227,1% |
| Рабочая память процесса (RSS) | 551,8 МиБ | 553,4 МиБ |

p95 вычислен линейной интерполяцией по 20 наблюдениям. Все наблюдения
сохранены: **максимум 4031,7 мс** на первом повторе после холодной попытки;
19/20 получений PCM быстрее 1500 мс. Влияние дополнительной JIT-подготовки
отдельно не выделялось. Это статистика TTS → PCM, **не конец речи → звук**.
CPU получен из process_time, включает все потоки процесса, имеет грубую
дискретность на коротких вызовах. На этой машине 12 логических CPU:
198% соответствует примерно 16,5% суммарной вычислительной ёмкости.

Холодный процесс, веса уже на диске, **n=1**:

- Импорт PyTorch, проверка и загрузка модели: **3793,9 мс**.
- Первый inference: **5319,4 мс**.
- Подготовка + первый PCM: **9113,3 мс**.
- RSS до: **28,5 МиБ**; после загрузки и первого inference: **505,6 МиБ**.
- Пиковый RSS всего процесса, включая отменённый длинный фрагмент: **580,4 МиБ**.

Это холодный процесс, не принудительная очистка файлового кэша Windows.
Для одного холодного запуска распределение медианы/p95 не заявляется.

Первая загрузка из сети через **настоящий адаптер**, отдельный пустой кэш:
загрузка + загрузка модели **41 144,7 мс**, первый inference **6486,9 мс**,
итого до PCM **47 631,6 мс**; `.part` после успеха нет, 24000 Гц подтверждены.
Данные: [silero-first-download-results.json](silero-first-download-results.json).
Это зависит от сети и не смешивается с повторными офлайн-вызовами.

На настоящем inference отмена после входа в `apply_tts`: coroutine вернулась
через 3,2 мс, native worker завершился через **544,3 мс**; вызов модели **один**,
PCM наружу **0**, следующие фрагменты не запускались. Эти два времени не
измеряют воспроизведение или акустическую остановку.

Настоящий PCM Silero также проверен через существующий контроллер и нативный
QAudioSink: результат приведён в
[silero-native-playback-results.json](silero-native-playback-results.json).
Выход беззвучный; **фактический первый звук и акустическая остановка не измерялись**.

## Моки и регрессии

11 тестов адаптера используют поддельные веса/loader: загрузка, SHA/cache,
офлайн-кэш, неполный/неверный download, отмена download, безопасные ошибки,
невалидный PCM, reuse модели, поздний executor result, отмена очереди Runtime,
сохранение истории/целостность слов и отсутствие следующих фрагментов.
Отдельный процесс Qt проверяет настройки всех четырёх движков, голос,
состояния загрузки и отсутствие импорта torch в GUI. Для атомарного кэша весов
уточнён статический запрет временных файлов: PCM по-прежнему только в RAM;
тест проверяет, что на диске остались только исходные байты весов.

Полный набор: **228 тестов, OK, 30,544 с**. GUI `--smoke`: **exit 0**.
Независимое read-only ревью адаптера, отмены, кэша и UI не нашло важных дефектов.

## Границы результата

Silero не устраняет прежние физические ложные прерывания/потери аудиокадров,
зафиксированные в [финальном аудите](final-release-validation.md). Их исправление
не заявляется. Физические наушники/динамики с Silero заново не проверялись;
голосовой Stop/barge-in сохранены на уровне прежнего механизма и регрессий.
Полный облачный LLM → Silero E2E не измерялся; квота LLM остаётся отдельным
ограничением. Общую цель 1500 мс и готовность всего Alice к релизу эти результаты
не подтверждают. Пользовательские ключи/провайдеры не менялись.
