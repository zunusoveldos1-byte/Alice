# Восстановление ответов Alice: Ollama + Silero

21 октября 2026. Ошибка на скриншоте — HTTP 429 от выбранной Gemini,
не ошибка синтезатора Silero. Реальная проверка API вернула суточную квоту
20 запросов для `gemini-2.5-flash` и отказ генерации. Доступность списка
моделей HTTP 200 не означает доступность генерации.
[Диагностика без секретов](gemini429-diagnostic.json),
[официальное описание лимитов Gemini](https://ai.google.dev/gemini-api/docs/rate-limits).

Пользователь явно выбрал полностью локальный режим и подтвердил закрытие
прежнего окна. Установлена официальная [qwen3:1.7b](https://ollama.com/library/qwen3:1.7b),
1 359 293 444 байта, с проверкой digest самим Ollama. Сервер Ollama 0.40.6.
[Факт установки и digest](local-ollama-install.json).

После успешной проверки сохранено:

- LLM: `ollama`, `qwen3:1.7b`, `http://127.0.0.1:11434`.
- TTS: `silero`; выбранный пользователем голос `aidar` сохранён.
- Ожидание тишины: 650 мс; остальные настройки сохранены.
- Ключ Gemini не удалялся и не переносился из Credential Manager.

Изменения кода:

- Gemini HTTP429 различает суточную квоту и временное превышение лимита;
  сообщение показывает причину и действие, не выводит тело ошибки/ключи.
  Нет автоматической смены модели или повторных запросов при исчерпании квоты.
- Для Qwen3 голосовой запрос передаёт `think:false`: ограничение короткого
  ответа не должно целиком расходоваться на скрытое рассуждение. Другие
  семейства Ollama не менялись. Служебное `message.thinking` не озвучивается.

## Реальная проверка

Три запроса прошли через настоящую Ollama, Silero и QAudioSink до полного
завершения воспроизведения, без ошибок:

| Запрос | Ответ | Текст → ActiveState |
|---|---|---:|
| Приветствие | «Привет! Как могу помочь?» | 15 339 мс |
| Два плюс два | «Два плюс два равно четыре.» | 288 мс |
| Первый месяц | «Январь.» | 160 мс |

Первая строка включает холодную подготовку TTS нового процесса. Первая
загрузка Ollama до этого также требовала дополнительного времени.
Это не распределение задержки конца речи и не акустическое измерение:
запросы текстовые, микрофон не использовался, громкость теста 0.
Все три результата и завершение служб:
[local-pipeline-verification.json](local-pipeline-verification.json).
В диагностическом скрипте между запросами исправлен сброс номеров PCM;
результат относится к повторному успешному полному прогону.

Полный unittest: **232 теста, OK, 24,337 с**. GUI `--smoke` после сохранения
локальных настроек: **exit 0**. Alice запущена заново с сохранёнными настройками.
Это устраняет зависимость голосовых ответов от квоты Gemini, но не исправляет
раньше обнаруженные физические ложные прерывания/потери аудиокадров.
Локальная текстовая Qwen3 не заменяет мультимодальный Gemini для анализа экрана.
