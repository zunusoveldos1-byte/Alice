# Оптимизация обновления интерфейса — 30 октября 2026

Раньше `_tick` вызывал полный `_render` на каждом кадре при включённом движении.
При периоде 50 мс это повторяло обновление контролов, чтение текста ответа,
подготовку журнала и подбор длины последней реплики до 20 раз в секунду.

Теперь полный рендер вызывается при `dirty`: уведомлении контроллера,
изменении настроек, геометрии, страницы или минут на часах. Сфера, волна,
сглаживание уровня звука и мини-окно обновляются отдельным методом
`_render_voice_frame`. Он работает и без новых событий контроллера.
Облегчённое оформление останавливает декоративную фазу, сохраняя реакцию
на звук; при неизменном визуальном состоянии перерисовка не запрашивается.

Подбор длины последней реплики кешируется по тексту, фактической ширине,
шрифту, DPI и devicePixelRatio. Ключ проверяется каждый видимый кадр, поэтому
переносы обновятся и после отложенного изменения размеров Qt. Алгоритм
усечения до двух строк сохранён. События контроллера, включая обновления
уровня микрофона, по-прежнему могут помечать содержимое изменённым; кеш
защищает измерение текста и при таких повторных полных рендерах.

## Измерение

`scripts/qa_ui_render_cache.py` запускает 120 ускоренных кадров одного окна
800×700 с длинной неизменной репликой. Включены анимации, обработка Qt events
и рисование offscreen. Часы фиксированы. Микрофон, LLM и другие провайдеры
не запускаются. Исходный код измерен до изменения, новый — после, в разных
процессах и без параллельных тестов.

| Показатель, 120 кадров | До | После |
|---|---:|---:|
| Полных обновлений содержимого | 120 | 0 |
| Созданий QFontMetrics для последней реплики | 120 | 0 |
| Время прогона | 2740,5 мс | 1814,8 мс |
| Процессорное время процесса | 3140,6 мс | 2218,8 мс |
| Анимация продолжалась | Да | Да |

В этом прогоне процессорного времени затрачено примерно на 29,4% меньше.
Это один искусственный offscreen-сценарий с неизменным текстом, не процент
загрузки CPU в реальной работе и не гарантированный выигрыш для всех окон.
Шрифты и графический backend влияют на время; системные шрифты в профильном
скрипте отдельно не загружались. Повторное измерение на новой версии не
воспроизводит baseline автоматически — он записан до правки кода.

Данные: [до](ui-render-cache-baseline-results.json),
[после](ui-render-cache-after-results.json).

```powershell
.\.venv\Scripts\python.exe scripts\qa_ui_render_cache.py --output docs\ui-render-cache-after-results.json
```

## Проверки

Полный набор `python -m unittest discover -s tests -v`: **450 тестов, OK,
68,420 с**. Изменённые Python-файлы проверены через `compileall`.

Новые Qt-тесты проверяют отсутствие полных рендеров при неподвижном содержимом,
продолжение анимации, повторное использование расчёта текста, его обновление
при смене текста/ширины/шрифта, очистку реплики, живое сглаживание уровня,
реакцию на выходной PCM и работу при отключённом декоративном движении.
Существующие проверки охватывают потоковый ответ, смену минут, мини-окно,
свёрнутое окно и адаптивную геометрию.

Окно дополнительно отрисовано и осмотрено при 480×560 и 1280×850 с явно
загруженным Segoe UI: кнопки доступны, длинная реплика помещается в две строки.
Настройки микрофона и моделей не изменялись.
