# Локальное распознавание Vosk + Whisper

Пользователь выбрал гибрид: быстрые команды/прерывания Vosk, окончательный
текст полного запроса Whisper. Альтернатива — большая модель Vosk 1,8 ГБ —
требует меньше кода, но больше памяти. Сейчас установлена small-ru-0.22:
физическая фраза «Найди погоду в Бишкеке» стала «найти погода в печке».

Решения реализации: faster-whisper small, CPU int8, четыре потока; модель
скачивается отдельной подготовкой, приложение использует только локальные
файлы. Настройка `stt_backend` позволяет выбрать vosk/hybrid. Старая
конфигурация по умолчанию остаётся vosk; после проверки включаем hybrid
в текущем settings.json. Каталог модели задаётся в настройках.

Vosk продолжает частичные результаты и прямые «Стоп/Замолчи/Хватит» без
дополнительного ожидания. Для остальных фраз передаётся весь PCM с прероллом
и паузами в ограниченную очередь отдельного потока. Захват не ждёт inference.
Дедупликация, epoch, generation и revision сохраняются. Отмена, повреждение
аудио и завершение сессии запрещают доставку устаревшего результата.
В режиме ярмарки остаётся существующая проверка владельца; гибрид применяется
только в обычном разговоре. Максимум PCM соответствует max_phrase_s с
прероллом и кадром запаса; переполнение явно отклоняет фразу.

Модель отсутствует/не загружается — понятная ошибка включения микрофона.
Ошибка inference — понятное уведомление, без молчаливой подмены текстом Vosk.
Аудио не записывается на диск и не отправляется в сеть. Отказ от сетевого
STT, замены LLM и подмены «печке» на «Бишкеке» регулярным выражением.

Проверки: неправильный Vosk → исправленный Whisper, точные stop-команды,
сохранение начала и пауз PCM, отмена/повреждение/смена сессии, ограничение
очереди, ошибка модели/inference, пустой результат, legacy-конфигурация,
нативное сравнение на синтетических фразах и повтор на живом микрофоне.
