# Четыре этапа Alice

Запрос пользователя: команды Windows → постоянная память → поиск через Firefox → активация только голосом владельца. Выполнение в текущем чате, без повторного согласования уже порученной работы.

Архитектура: существующие CaptureWorker / VoiceSessionController / DialogRuntime сохраняются. Детерминированные команды обрабатываются перед LLM, результаты озвучиваются прежней очередью. Распознанный текст никогда не исполняется в shell. Модель не получает произвольное исполнение команд.

1. Windows: фиксированный список приложений, параметры Windows, громкость/mute с readback, рабочий стол. Отмена до побочного эффекта; недоступность объясняется явно. Выключение/перезагрузка не входят в первоначальный набор.
2. SQLite-память: явно сохранённые факты, просмотр, удаление одного/всех, ограниченный контекст для ответов. Аудио/полная переписка автоматически не сохраняются.
3. Firefox: поиск по запросу и внутри указанного публичного сайта, открытие URL. Поиск открывает страницу результатов, не выдаёт её за прочитанную. Исполняемый файл определяется по установленным путям/реестру или задаётся пользователем; нет подмены стандартным браузером.
4. Локальная проверка говорящего: sherpa-onnx speaker embedding, три речевых образца, сохранение только усреднённого вектора с идентификатором модели. Проверка каждого законченного запроса и команд остановки; неподтверждённые partial не прерывают ответ. Режим закрыт при отсутствии/повреждении профиля. Регистрация из GUI, запись только после кнопки пользователя, отмена освобождает микрофон. Это фильтр говорящего, не защита от воспроизведения записи.

Проверки: сначала падающие тесты каждого контракта, затем реализация; интеграция с существующими тестами аудио/отмены; полный unittest и GUI smoke. Реальная регистрация/проверка владельца требует речи пользователя и контрольной чужой речи.

Статус: этапы 1–4 реализованы; 286 тестов OK, GUI smoke OK, модель реально загружается, две синтетические чужие речи отклонены. Пользователь зарегистрировал три образца своего голоса; файл профиля и совпадение модели проверены. После регистрации пользователь подтвердил: обычная голосовая команда сохранения факта распознана, Alice ответила «Запомнила». Сводка — docs/four-stages-validation.json, руководство — docs/four-stages-guide.md.
