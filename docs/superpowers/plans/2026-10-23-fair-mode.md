# Режим «Ярмарка»

Цель: ограниченный приём явных команд в шумном помещении. Существующие VAD,
Vosk, проверка владельца, очередь озвучки и подтверждения питания сохраняются.

1. RNNoise: один потоковый экземпляр на поток захвата, 16 кГц mono → потоковый
   ресемплинг 48 кГц → кадры 480 → RNNoise → 16 кГц → кадры 512.
   Непрерывные состояния, ограниченные буферы, никакого автоматического усиления.
   Выключено сохраняет прежний тракт. Ошибка зависимости не включает скрытый fallback.
2. Активация: точное имя «Алиса» в начале финальной фразы или короткое окно после
   отдельного имени; один запрос закрывает окно. Продолжение разговора выключено.
   Удержание — независимый явный канал, с предварительным буфером и финализацией
   при отпускании. Глобальная клавиша Ctrl+F8 настраивается; повтор клавиши не дублирует запрос.
3. Колонки: явно обозначенный полудуплекс без AEC. Во время выхода и хвоста команды
   блокируются. Удержание останавливает выход и ждёт хвост перед состоянием «Слушаю вас».
4. Проверка владельца переиспользует существующие ONNX embeddings и локальный профиль.
   Для явного удержания проверка личности не требуется; обычная активация её сохраняет.
   Не показывать процент уверенности; совпадение текста не является проверкой личности.
5. Настройки и UI: компактный раздел, VAD/порог STT/имя/окно/продолжение/клавиша,
   кнопки удержания на главном и мини-окне. Короткий микрофонный тест только по кнопке,
   исходное/обработанное PCM в RAM, уровень/VAD/перегрузка, воспроизведение без файлов.
6. RED/GREEN: размеры и непрерывность, границы очереди, одиночная загрузка, чужие
   фразы, одноразовое окно, удержание/отпускание/преролл, блокировка своей озвучки,
   сохранение подтверждений и проверка GUI. Native RNNoise + полный unittest.

Реальных согласованных записей пользователя нет. Проверка толпы и перекрывающейся
речи будет отмечена как непроведённая; рекомендуемый демонстрационный режим —
удержание кнопки и близкий микрофон. RNNoise не отделяет владельца от других людей.
