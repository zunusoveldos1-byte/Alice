# Четыре этапа Alice

22 октября 2026. Реализовано в существующем конвейере, без переноса голосового движка Eidos.

## 1. Команды Windows

Произносите явную команду:

- «Открой блокнот», «Запусти блокнот», «Открой калькулятор», «Открой проводник».
- «Открой настройки Windows», «Открой настройки звука».
- «Покажи рабочий стол», «Сверни все окна», «Заблокируй экран».
- «Сделай громче», «Сделай тише» — шаг 10 процентов.
- «Установи громкость пятьдесят процентов», «Какая сейчас громкость».
- «Выключи звук», «Включи звук» — это системный звук Windows, не только Alice.
- «Что ты умеешь» — подсказка по командам.

Выполняются только известные команды; произвольные shell-команды и код модели не исполняются. Запуск приложения подтверждает принятие запроса Windows, не появление его окна. Изменение громкости проверяется обратным чтением. Выключение и перезагрузка компьютера не добавлены. Переключатель «Команды Windows и поиск через Firefox» находится в настройках.

## 2. Постоянная память

- «Запомни: меня зовут Элдос» — сохранить явно продиктованный факт, получить номер.
- «Что ты помнишь», «Покажи память» — до 20 последних записей с номерами.
- «Забудь факт один» / «Забудь номер 1» — удалить запись.
- «Очисти всю память» — удалить все факты.

Файл `data/memory.sqlite3` остаётся между запусками. Подтверждённый профиль владельца,
предпочтения, остальные факты и производные резюме хранятся раздельно. Обычная
беседа и ответы модели не меняют профиль. Приветствия, тестовые фразы, цитаты и
ролевые примеры не сохраняются как личные факты. Если имя уже сохранено, замена
требует отдельного нового «Да»; «Нет», «Стоп» и истечение 30 секунд отменяют её.
«Как меня зовут?» читает подтверждённое имя, а не просит модель угадать его.

Подтверждённая память кэшируется; приветствия не запускают чтение базы. Только
подтверждённые профиль/предпочтения и до 10 фактов добавляются к подходящему
свободному вопросу как справочные данные. Производные резюме не становятся
подтверждённым профилем. Облачный провайдер получает переданные ему факты вместе
с вопросом. Аудио и полные разговоры автоматически не записываются. Запись
ограничена 600 символами, всего до 1000 записей; база локальная, без шифрования.

В «Настройки → Общие → Просмотреть / исправить сохранённые факты» можно увидеть
источник и статус каждой записи, исправить или удалить её. Старые записи без
происхождения сначала исключаются из активной памяти и доступны для проверки.
Отключение памяти не удаляет файл. Подробности миграции и проверок:
[исправление памяти владельца](owner-memory-validation.md).

## 3. Поиск через Firefox

- «Открой Firefox».
- «Найди в интернете рецепт блинов».
- «Найди в Firefox документацию Python».
- «Найди на сайте mozilla.org настройки приватности».
- «Найди на сайте википедия силу тяжести».

Поддерживаются голосовые имена сайтов: википедия, гитхаб, ютуб, мозилла. Для других сайтов нужен корректно распознанный публичный домен. Открывается Google-поиск в новой вкладке Firefox; поиск внутри сайта использует `site:домен`. Alice сообщает об открытии, не утверждает, что прочитала результаты. Не используется другой браузер, если Firefox недоступен. В настройках можно указать абсолютный путь к `firefox.exe`; по умолчанию используются реестр Windows и стандартные каталоги установки.

## 4. Только мой голос

Это локальная проверка говорящего перед каждым завершённым голосовым запросом. Один ключевой сигнал или слово «Алиса» не используется как подтверждение личности; ключевое слово вообще не требуется. Нажмите микрофон, чтобы начать слушание. Режим не включает микрофон при запуске автоматически.

Однократная установка в новом окружении:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-speaker.txt
.\.venv\Scripts\python.exe scripts\prepare_speaker_model.py
```

Используется CPU-модель WeSpeaker English VoxCeleb ResNet34 из
[официального выпуска sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-recongition-models),
интеграция следует [официальному API проверки говорящего](https://k2-fsa.github.io/sherpa/onnx/speaker-identification/index.html).
Модель распознавания говорящего не является распознавателем русского текста. Качество на русском голосе владельца необходимо проверить непосредственно после регистрации.

Регистрация: «Настройки → Общие → Зарегистрировать / перезаписать мой голос». Текущий микрофонный сеанс останавливается, открывается окно. Нажмите «Начать регистрацию» и прочитайте три появляющиеся фразы по 7 секунд. Используйте обычный голос в тихой комнате. Сохраняется только усреднённый вектор в `data/owner.json` и SHA-256 модели; аудиозаписи остаются в RAM. Успешная регистрация автоматически сохраняет включённый режим «Только мой голос». Закройте окно и включите микрофон снова.

Проверяется вся фраза перекрывающимися окнами, включая её начало. Проверка работает вне capture-потока; очередь ограничена одной проверкой. Если она занята, следующая фраза может быть пропущена. Непроверенные partial не запускают запрос и не прерывают озвучку. Команды стоп и отключения микрофона тоже требуют подтверждения владельца; ручные кнопки доступны всегда. Фразы короче секунды и очень тихая речь отклоняются. Длинные паузы внутри фразы могут привести к отказу. Профиль, модель или зависимости отсутствуют/повреждены — запросы не допускаются; автоматического перехода к любому голосу нет.

Порог совпадения по умолчанию 0,65; его можно менять в настройках. Снижение повышает риск принятия чужого голоса. Проверка говорящего вероятностная: это фильтр удобства, не средство защиты от воспроизведения записи или качественной имитации. Нельзя обещать абсолютное «только я» без испытаний своего и чужого голоса. Профиль удаляется удалением `owner.json`, после чего режим снова блокирует голосовые запросы до регистрации; отключение режима явно разрешает любой голос.

## Проверки

Автоматические проверки покрывают: явные команды и shell-инъекции; открытие именно Firefox; сохранение/чтение/очистку SQLite; отмену при блокировке базы; сохранение прежнего профиля при отмене до замены; пропуск чужого голоса; весь PCM длинной фразы с чужим началом; озвучивание локальной команды без LLM; настройки и отмену окна регистрации. Физическая регистрация и проверка на чужой речи требуют участия владельца.
