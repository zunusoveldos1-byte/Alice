# Открытие YouTube — 31 октября 2026

Команда на скриншоте распознана правильно, «Открой YouTube.».
Причина уточнения: общий шаблон `открой <название>` в fast_intent
возвращал `launch_app`, и DesktopBackend искал YouTube среди установленных
приложений. Имена сайтов без домена отдельного маршрута не имели.

Перед общим шаблоном добавлено распознавание YouTube/ютуб/ютьюб/ю туб
для команд открытия/перехода. Результат: `browser_open` с адресом
`https://www.youtube.com/`. Варианты «Открыть браузер», «мой браузер»,
вежливые формы также направляются в browser_open. normalize удаляет
пунктуацию, добавленную STT. Произвольные сайты/приложения не угадываются.

Firefox остаётся браузером текущего существующего адаптера, учитывается
путь firefox_path. Разрешение permission_browser, отрицания и отмена
по-прежнему проверяются до запуска. Скриншот для этой команды не нужен.

Новые регрессии воспроизвели неверную маршрутизацию до исправления и
проходят после: 15 тестов test_context_tools.py, OK. Нативный вызов
ToolRouter.handle('Открой YouTube.') вернул done/browser_open с ожидаемым
адресом и запустил Firefox. Обнаружено окно «YouTube — Mozilla Firefox»;
содержимое страницы/проигрывание видео не проверялись.
Полный набор: **497 тестов, OK, 54,503 с**. GUI smoke: exit 0.
Alice заново запущена из обновлённых исходников.

Наблюдение экрана не является постоянным: observe_context читает HWND,
название/процесс/границы активного окна, а не изображение. Для передачи
изображения есть отдельный запрос экрана с предпросмотром. Изменение
маршрутизации YouTube не добавляет постоянного визуального наблюдения.
