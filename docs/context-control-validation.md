# Контекстное управление — 23 октября 2026

## Реализовано

Намерение отделено от исполнения. Знакомые фразы разбираются локально, остальные
команды — выбранной моделью. Ответ проходит закрытую схему зарегистрированного
инструмента. Ollama получает JSON Schema и контекст 8192. Код модели и произвольные
команды оболочки не исполняются. Контекст: последнее внешнее активное окно и четыре
последние реплики; их содержимое помечено как недоверенные данные.

- Каталог ярлыков «Пуск» и App Paths, запуск приложений и игр, выбор при неоднозначности.
- Окна: переключение, сворачивание, разворачивание, восстановление, штатное WM_CLOSE.
  Диалог сохранения приложения сохраняется; процессы принудительно не завершаются.
- Настройки Windows, громкость с проверкой, аппаратная яркость WMI, медиа, рабочий
  стол, блокировка, папки пользователя, сайты и поиск в Firefox.
- Скриншоты в RAM/буфер обмена. Семь независимых разрешений, журнал 40 действий,
  поле текстовых команд, общий статус и кнопка «Стоп».
- Питание: исходный запрос, отдельное согласие, отдельная точная финальная фраза.
  Повтор реплики не считается новым подтверждением. Таймаут 30 секунд, отмена на
  каждом этапе, проверка разрешения и ожидание отображения финального состояния.
  Ключ /f не используется. Для первого голосового согласия можно сказать
  «Да, я подтверждаю», чтобы хватило длительности для проверки владельца.
  Финал: «Подтверждаю выключение» / «Подтверждаю перезагрузку».
- Меню игр: локальный OCR, один клик перед повторным наблюдением, максимум четыре
  клика. HWND, физические координаты, свежесть снимка, разрешения и отмена проверяются
  перед вводом. Поддержаны однозначные текстовые Settings/Options/Настройки,
  категории, просмотр числовых параметров и изменение через кнопки +/− с проверкой.

Короткие «Стоп», «Нет», «Отмена» могут только отменять управление без проверки
личности. Они не разрешают новые действия и не подтверждают питание. Обычные
команды сохраняют проверку владельца; она не защищает от воспроизведения записи
или подделки голоса.

## Проверено

- Полный unittest: голосовой конвейер, память, проверка владельца, схемы, разрешения,
  выбор окон, отрицательные команды, отмена, таймауты, отдельные подтверждения и GUI.
  Реальное исполнение питания подменено.
- GUI smoke открывает и закрывает интерфейс без микрофона.
- Установленная Qwen3:1.7b правильно разобрала «Пожалуйста, запусти мне блокнот»,
  «Снизь системную громкость на пять процентов», «Зайди в настройки игры».
  Инструменты при этой проверке не исполнялись.
- Windows OCR распознал синтетическое изображение и настоящее окно GeoGuessr.
  Исправлены чтение пути процесса и физические координаты при масштабе Windows 125%.
- GeoGuessr Steam Edition запущена через установленный ярлык; главное меню считано.
  Кнопка настроек не распознана однозначно: сценарий предложил ручной шаг без кликов.
  Позднее Windows отклонила активацию окна; ввод не отправлялся.
  **Автоматическое открытие настроек GeoGuessr пока не подтверждено.**
  Пользователь уточнил, что настройки доступны во время игры. Если кнопка отсутствует,
  Alice предлагает войти в игру и повторить команду открытия настроек; сама матч не запускает.

## Пока недоступно или не проверено на оборудовании

Иконки без текста и произвольные ползунки не поддерживаются. Определение игрового
контекста использует известные имена процессов/окон; неизвестную игру следует
назвать явно. Неизвестный экран не считается игровым процессом. Защищённый ввод
и ограничения Windows дают ручной следующий шаг.
Разрешение и режим экрана остаются ручным действием с просмотром распознанных
значений; автоматическая смена и сохранение не выполняются.
Яркость зависит от оборудования; реальный дисплей не изменялся.
Фактическое выключение и перезагрузка не выполнялись.
Каталог ярлыков не гарантирует обнаружение всех программ. Запуск, вкладки и медиа
обозначаются как отправленный запрос, если конечное состояние не проверено.
Универсальная поддержка игр не заявляется.

## Использование

OCR в этой среде установлен. На другом Windows-компьютере:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-automation.txt
```

Альтернатива — extra `.[automation]`. Нужны доступные языки OCR Windows.
Ввод, игры и питание по умолчанию выключены и включаются отдельно в настройках.
После обновления перезапустите работающий экземпляр Alice для загрузки нового кода.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
.\.venv\Scripts\python.exe -m alice_voice --smoke
```
