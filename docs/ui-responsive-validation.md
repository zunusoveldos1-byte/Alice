# Адаптивность, оконные кнопки и WMC-анимации

Изменены alice_voice/ui/main_window.py и alice_voice/ui/widgets.py.

- Удалён фиксированный минимум 1100×850 и отключено неявное ограничение
  главного layout. Основная карточка и нижние панели находятся в прозрачном
  QScrollArea. При ширине viewport менее 1050 px панели идут вертикально,
  на широком окне — в ряд. Шапка остаётся доступной независимо от прокрутки.
- На ширине окна менее 1100 px навигация переносится во вторую строку.
  Второстепенные элементы шапки скрываются по мере уменьшения ширины.
  Динамические URL/длинные слова не растягивают содержимое горизонтально;
  высота перенесённого текста учитывается компоновщиком.
- Свернуть/развернуть/закрыть — рисуемые векторные кнопки 40×40 логических
  пикселей. Есть мягкая подсветка, клавиатурный фокус, подсказки и доступные
  имена. Состояние «восстановить» отслеживает WindowStateChange.
- Добавлен QSizeGrip в нижнем правом углу. Безрамочность, прозрачные углы,
  системное перемещение за шапку и запасное перетаскивание сохранены.
- Внизу фона движутся две независимые синусоидальные ленты, по углам —
  мягкие цветовые переливы. Растеризация выполняется при смене размера,
  DPI или темы; кадр лишь смещает готовые поверхности.
- EntranceFade использует временный QGraphicsOpacityEffect на 280 мс
  с easing. Он работает при запуске, переходе на «Главную» и открытии
  существующих модальных диалогов. Эффект удаляется после завершения;
  дополнительных таймеров анимации нет. set_motion_enabled(False)
  немедленно завершает эффекты и отключает дальнейшие анимации.

Проверки:

- Полный набор: 97 тестов, OK (15.051 с).
- python -m alice_voice --smoke: код 0; pip check: зависимости согласованы.
- Четыре новых subprocess Qt-теста проверяют маленькое окно, прокрутку
  до последней панели, длинные URL/слова, отсутствие пересечения микрофона
  и статуса при переносе фразы, возврат в широкую компоновку, оконные кнопки,
  завершение/отключение эффектов, модальный цикл и перемещение за шапку.
- Нативные скриншоты Windows при 125% DPI проверены на ширинах 1280, 800,
  420 и 360 логических пикселей; горизонтальная прокрутка при 360–800 px
  отсутствует, нижняя панель доступна через вертикальную прокрутку.
- Независимое ревью выявило и помогло закрыть растягивание длинным текстом;
  отдельная нативная проверка выявила недостаточную высоту при переносах.
  Оба случая воспроизведены тестами до исправления.

Последний краткий нативный замер (параллельно запускались тесты): 39 кадров
за 2.201 с, 1.203 с CPU процесса; при сворачивании — 0 кадров / 0.000 с CPU
за 1.1 с. Нагрузка зависит от окружения; это не гарантия FPS или CPU.
Fade-In не оставляет постоянного эффекта композиции после завершения.
