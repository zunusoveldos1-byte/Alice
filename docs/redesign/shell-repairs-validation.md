# Alice Voice: исправления оболочки, 22 октября 2026

## Причины и изменения

- Мини-ассистент создавался как зависимый QDialog основного окна. Прямое открытие в исходной версии удалось воспроизвести успешно; абсолютная неработоспособность не подтвердилась. Зависимость от основного окна и отсутствие собственного управления перемещением устранены: теперь это независимый QWidget Tool/WindowStaysOnTop с сохранённым экземпляром, заголовком для перетаскивания, атомом, микрофоном, остановкой, паузой и возвратом. Новый контроллер, сервисы и история не создаются. Закрытие скрывает мини-окно.
- Настройки открывались исключительно модальным exec(). Те же поля, валидация, безопасное хранилище ключей и SettingsStore теперь используются во встроенном виджете Qt.Widget в QStackedWidget. Семь категорий имеют отдельную прокрутку. Камера использует существующий обработчик; горячие клавиши показаны как справка, без фиктивных переключателей. Системный промпт редактируется многострочно. При отмене ключи очищаются; при ошибке сохранения остаются для повторной попытки.
- Часы форматировались как HH. Теперь используется HH:mm, ширина минимум 80 логических пикселей, системное время автоматически проверяется таймером.
- Проверка LM Studio ранее связывалась с probe_tools(). Добавлен отдельный probe_text(), получение списка моделей и независимая проверка реального текстового ответа; инструменты и vision для этого не требуются. Результаты устаревшего запроса отбрасываются. Таймаут и ошибки сервера показываются с инструкцией. Существующий LLMProvider продолжает маршрутизировать LM Studio в /v1/chat/completions с потоковым выводом, отменой и передачей фрагментов в общий TTS-конвейер.
- reduced_motion сохраняется в Settings. Изменение только оформления или громкости не отменяет активный ответ и не перезапускает runtime.

## Внешнее ограничение LM Studio

На диске найден файл `C:/Users/Элдос/.lmstudio/models/lmstudio-community/gemma-4-E4B-it-GGUF/gemma-4-E4B-it-Q4_K_M.gguf`. Это имя файла, не подтверждённый API ID.

Запрос к `http://127.0.0.1:1234/v1/models` получил отказ подключения WinError 10061. CLI сообщает `The server is not running`, а `lms server start --port 1234 --bind 127.0.0.1` завершился с `LM Studio daemon is not running and no valid installation could be found or installed`. Найдено приложение Bionic, отдельный продукт LM Studio; доступ к его окну через Computer Use не был получен: запрос истёк.

Фактический API ID Gemma не получен и не подставлялся. Пользовательский settings.json не заменялся непроверенной конфигурацией. Реальный ответ этой Gemma, её отмена, озвучивание и vision не проверены. Для продолжения требуется включить Local API Server в LM Studio/Bionic, получить модели на встроенной странице, выбрать реальный ID, проверить ответ и сохранить провайдера LM Studio.
