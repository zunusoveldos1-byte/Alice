# Alice Voice: cosmic redesign

Implement the supplied Russian brief and reference in the existing PyQt6 application.
The shared VoiceSessionController and SettingsStore retain ownership of the voice session,
providers, history and persisted volume. Page navigation only changes stacked widgets.

1. Replace the card-based shell with sidebar, top model selector and voice/dialog/work pages.
2. Add bounded QPainter sphere, orbit ribbons, quiet starfield and diffuse bottom atmosphere;
   use existing 20 FPS clock, smoothed mic RMS and playback-position PCM RMS.
3. Connect volume hover/focus popup, more menu, shared-session mini window and Qt camera.
4. Exercise navigation/session preservation, silence, popup persistence and camera lifecycle;
   run existing backend tests, compile, smoke and capture actual Qt render at multiple sizes.

No new dependencies; camera starts only on explicit click. Hidden windows stop decoration.
Reduced motion uses the existing set_motion_enabled API. No synthetic audio activity.
